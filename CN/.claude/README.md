## 创建的文件结构

```javascript
CN/.claude/
├── CLAUDE.md                 # 主入口文件
├── .gitignore               # Git忽略规则
├── rules/
│   ├── stack.md            # 技术栈总纲
│   ├── frontend.md         # 前端规范 (React/Vite/TS/Tailwind)
│   ├── backend.md          # 后端规范 (FastAPI)
│   ├── database.md         # 数据库规范 (SQLite/SQLModel)
│   └── api-contract.md     # 前后端接口约定
└── tools/
    └── project-setup.md    # 项目脚手架指令
```

## 文件内容概述

- __CLAUDE.md__: 项目规则体系的入口文件，介绍技术栈组合和规则结构
- __.gitignore__: 包含Python、Node.js、SQLite等相关忽略规则
- __stack.md__: 详细的技术栈架构、开发环境和包管理配置
- __frontend.md__: React + Vite + TypeScript + Tailwind CSS 的完整前端规范
- __backend.md__: FastAPI框架的详细后端开发规范和最佳实践
- __database.md__: SQLite + SQLModel 的数据库设计和优化规范
- __api-contract.md__: 前后端API接口的详细约定和规范
- __project-setup.md__: 完整的项目初始化和开发环境搭建指南

所有文件均使用中文编写，内容详尽，包含代码示例、配置模板和最佳实践指南，为长期运行的智能体提供了完整的技术栈规则体系。
