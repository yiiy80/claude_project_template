# Claude 全栈プロジェクト規則体系

## プロジェクト概要

これは React + FastAPI + SQLite をベースとした全栈アプリケーションで、現代的な技術スタックとベストプラクティスを採用しています。

### 技術スタック組み合わせ
- **フロントエンド**: React + Vite + TypeScript + Tailwind CSS
- **バックエンド**: FastAPI (Python)
- **データベース**: SQLite + SQLModel
- **デプロイ**: 中小規模アプリケーションに適する

### 規則体系構造

```
.claude/
├── CLAUDE.md                 # メインエントリ (このファイル)
├── .gitignore                # Git無視規則
├── rules/
│   ├── stack.md              # 技術スタック総綱
│   ├── frontend.md           # フロントエンド規範 (React/Vite/TS/Tailwind)
│   ├── backend.md            # バックエンド規範 (FastAPI)
│   ├── database.md           # データベース規範 (SQLite/SQLModel)
│   └── api-contract.md       # フロントエンド・バックエンドインターフェース約定
└── tools/
    └── project-setup.md      # プロジェクト足場指令
```

## 使用ガイド

### Claude (AIアシスタント) 向け

1. **規則の厳格遵守**: あらゆるコード修正や新規機能追加時に、関連規則ファイルを事前に確認すること
2. **フロントエンド・バックエンド分離**: フロントエンドとバックエンドの責任境界を明確に区別し、混同しないこと
3. **インターフェース約定優先**: APIインターフェースの設計は `api-contract.md` の約定に従うこと
4. **ベストプラクティス**: 各技術スタックのベストプラクティスとプロジェクト規範に従うこと

### 開発者向け

1. **規則同期**: 開発前に関連規則ファイルを熟読すること
2. **コードレビュ**: 新しいコードが規則要件を満たしていることを確認すること
3. **ドキュメント更新**: 規則更新時にコード実装に同期すること

## 核心原則

### 1. フロントエンド・バックエンド分離
- フロントエンドはユーザーインターフェースとインタラクションロジックに集中
- バックエンドはビジネスロジックとデータ処理に集中
- RESTful API を通じて通信

### 2. 型安全性
- フロントエンドは TypeScript を使用して型安全性を確保
- バックエンドは Pydantic を使用してデータ検証を実施

### 3. 現代的な開発
- 最新のツールとフレームワークを使用
- 業界ベストプラクティスに従う
- 開発体験とコード品質を重視

### 4. 保守性
- 明確なコード構造
- 完全なドキュメント
- 一貫した命名規範

## クイックスタート

1. `rules/stack.md` を読んで技術スタック総綱を理解する
2. 需要に応じて対応する規則ファイルを参照する
3. `tools/project-setup.md` を参考にしてプロジェクト初期化を行う

## 注意事項

- この規則体系はこのプロジェクト専用にカスタマイズされている
- 特殊な需要がある場合は適宜調整可能
- 定期的に規則内容のレビューと更新を推奨
